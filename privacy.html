Privacy Policy

Last updated: 26 October 2026

This policy covers book-upload, a private desktop tool run by the creator of the DailyBookDose channel (contact: booktiktok@outlook.de). The tool uses the YouTube API Services to upload the channel's own videos to the channel's own YouTube account. It has exactly one user: the channel owner. It has no public sign-up and collects no data from viewers or other people.

YouTube API Services

book-upload uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

  • An OAuth access and refresh token for the channel owner's Google account, with the scope youtube.
  • The channel's own playlists (to file each video in the playlist of its book) and the id of each uploaded video.

The tool sends the channel's own video files, titles, descriptions, tags, thumbnails and publish times to YouTube. It does not read comments, analytics, subscribers or any data about other users or channels.

How data is used and stored

The tokens are stored only on the owner's computer, in a local file readable by the owner alone. Nothing is stored on a server, shared with third parties, sold, or used for advertising. Video ids and links are written to local project files so the owner knows what was uploaded.

Retention and deletion

Tokens are kept until the owner deletes the local file or revokes access. Access can be revoked at any time at Google Account → Security → Third-party apps (see security.google.com/settings/security/permissions). Revoking makes the stored tokens useless; deleting the local file removes them.

Cookies

This website and the tool use no cookies and no tracking.

Changes and contact

Changes to this policy are published on this page. Questions: booktiktok@outlook.de.
